AI事業部 開発指示書 No.013

提出日：2026/08/05

件名

Fishing Log App テスト公開対応（GitHub Pages）

【作業開始】
最初に以下のファイルを読み、内容を理解してから作業を開始してください。

docs/00-ai-development-rules.md docs/01-fishing-log-project-rules.md

内容を理解したことを最初に報告してください。
共通ルール、プロジェクトルール、本指示書の内容に矛盾がある場合は、実装を開始せず社長へ確認してください。

【背景】 Fishing Log
Appは主要機能の実装が完了し、ローカル環境での動作確認も完了しています。
現在はHTTPS環境でのみ利用できる機能（位置情報取得、Web Share
API等）の最終確認ができないため、GitHub
Pagesを利用したテスト公開環境を構築します。
今回の目的は、一般公開ではなく、実機テストを行うための公開環境を整備することです。

【目的】 GitHub Pages上へFishing Log
Appを公開し、HTTPS環境で以下の確認ができる状態にしてください。

・スマートフォンからアクセス ・位置情報取得 ・Web Share API ・JPEG共有
・カメラ利用 ・通常利用

【作業範囲】 ・GitHub Pages公開設定 ・公開に必要な設定変更 ・公開URL確認
・HTTPS確認 ・公開環境で必要となる最小限の修正 ・既存機能の動作確認

【変更禁止】 ・新機能追加 ・デザイン変更 ・UI改善 ・AI分析機能
・検索機能 ・統計機能 ・IndexedDB仕様変更 ・データ構造変更

【Git】 今回の作業では、GitHub
Pagesテスト公開のために必要なコミット・プッシュは実施して構いません。
公開後は追加変更を行わず停止し、社長へ完了報告を提出してください。
GitHub
Pages以外への公開、本番リリース、不要なブランチ操作は行わないでください。

【実装内容】 1. GitHub Pagesで公開可能な状態にしてください。 2.
公開URLを確認し、HTTPSでアクセスできることを確認してください。 3. GitHub
Pages上で正常表示できることを確認してください。 4.
画像、CSS、JavaScriptなどが正常に読み込まれることを確認し、必要に応じてパスを修正してください。
5.
公開後、釣果登録・編集・JPEG保存・SNSカード・JPEG共有・位置情報取得・カメラ利用が正常動作することを確認してください。
6. GitHub
Pages公開に伴う軽微な修正は行って構いません。ただし仕様変更は禁止します。

【実機確認】 ・HTTPS接続 ・スマートフォン表示 ・PC表示 ・JPEG保存 ・Web
Share API利用可否 ・位置情報取得可否 ・カメラ利用可否
Codexで確認できない項目は「実機確認が必要」と報告してください。

【テスト】 ・GitHub Pages公開設定確認 ・HTTPS確認
・JavaScript構文チェック ・既存テスト実施 ・git diff –check

【完了条件】 ・GitHub Pages公開設定完了 ・HTTPSアクセス可能
・公開URL確認 ・GitHub Pagesで正常表示 ・既存テスト成功
・JavaScript構文チェック成功 ・git diff –check成功
・UTF-8形式の開発完了報告書をdocsフォルダへ保存

【完了報告】 保存先 docs/development-report-no013-20260805.txt

報告書には以下を含めてください。 ・実装内容 ・変更ファイル
・追加ファイル ・公開URL ・GitHub Pages設定内容 ・HTTPS確認結果
・実施したテスト ・テスト結果 ・実機確認が必要な項目 ・残るリスク
・改善提案

Codex利用状況、作業規模、作業難易度については、共通ルールに従って報告してください。

【禁止事項】 ・GitHub Pages以外への公開 ・本指示書にない機能追加
・大規模なリファクタリング ・既存データ削除 ・IndexedDB初期化

実装、テスト、開発完了報告書の作成まで完了したら作業を停止し、社長の確認と承認を待ってください。
